# Semaforo-Raspberry-Pico
Simulação de um semáforo com botão de travessia para pedestres, feita com Raspberry Pi Pico no Wokwi. O código em C++ controla 5 LEDs (carros e pedestres), lê o botão com INPUT_PULLUP e debounce e conduz toda a sequência de sinais até liberar a travessia. Desenvolvida como parte de um portfólio prático de sistemas embarcados.
